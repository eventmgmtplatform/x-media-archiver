# Security policy

Report suspected vulnerabilities privately through GitHub Security Advisories for this repository.
Do not open a public issue containing cookies, tokens, signed URLs, local paths or user data.

Version 0.1.x receives best-effort security fixes while supported. Include the affected version,
platform, sanitized reproduction and impact. Maintainers will acknowledge, triage, coordinate a
fix and publish advisories when appropriate. Never attach real Firefox profiles or repositories.
