## 8. Defectos reproducidos que requieren rework

### F-01 — La ruta `"."` es aceptada

**Ubicación:** `src/xma/domain/identity.py:45-52`

El contrato prohíbe componentes `.` y `..`. Para `PurePosixPath(".")`, `parts` está vacío y la
validación devuelve `"."`.

```bash
PYTHONPYCACHEPREFIX=/tmp/xma-b02-audit-pycache \
.venv/bin/python -c \
'from xma.domain.identity import validate_relative_path; print(repr(validate_relative_path(".")))'
```

```text
'.'
```

Impacto: puede persistirse el directorio actual como ruta de artefacto normalizada.

### F-02 — DiscoveryRun no puede evolucionar

**Ubicación:** `src/xma/adapters/catalog/sqlite.py:171-198,345-359`

`put_discovery_run()` usa `_put_immutable()`. Un run `RUNNING` no puede actualizar estado,
`finished_at`, cursor ni conteos.

```text
run_update_result= IdentityConflictError discovery_runs identity conflicts with catalog
```

Impacto: el repositorio no puede persistir el ciclo de vida definido por el agregado. La
persistencia mínima de `DiscoveryRun` es parcial; esto no implica exigir `delete`.

### F-03 — Conexión abierta si falla `__enter__`

**Ubicación:** `src/xma/adapters/catalog/sqlite.py:370-376`

La conexión se crea antes de `migrate()` y `BEGIN`, pero se asigna a `self._connection` después.
Si la inicialización falla, `__exit__` no se ejecuta y la conexión no se cierra.

```text
connection_closed_after_enter_failure= False
```

Impacto: incumple el cierre determinista requerido.

### F-04 — DownloadJob acepta identidad de activo inválida

**Ubicación:** `src/xma/domain/models.py:134-136`

Solo se comprueba que `asset_id` contenga `":"`. El dominio acepta `asset_id=":"` sin validar
post ID ni media index.

```text
accepted_asset_id= ':'
```

Casos regresivos mínimos: `":"`, `"bad:0"`, `"1:-1"`, `"1:x"`.

### F-06 — `schema_version.applied_at` registra una fecha fija falsa

**Ubicación:** `src/xma/adapters/catalog/migrations.py:45-48`

Cada aplicación registra `2026-10-28T00:00:00.000000Z`, sin representar el momento real.

Impacto: metadatos falsos y pérdida de trazabilidad operativa. Debe registrarse un timestamp UTC
real mediante un mecanismo testeable; documentar una fecha falsa como marcador no es aceptable.

## 9. Observaciones y gaps de suficiencia

### O-05 — `updated_at` puede retroceder

**Ubicación:** `src/xma/domain/models.py:138-141,149-167`

Una transición acepta un instante anterior al `updated_at` actual si sigue siendo posterior a
`created_at`.

```text
accepted_time_regression= True
```

La monotonicidad frente al estado anterior no está formulada literalmente en el prompt. Se
registra como recomendación de coherencia temporal, separada de los defectos contractuales.

### O-06 — Test de matriz autorreferencial

**Ubicación:** `tests/domain/test_models.py:92-111`

La prueba deriva expectativas de `DOWNLOAD_TRANSITIONS`, la misma constante de producción. Aunque
ejercita ramas y la documentación coincide hoy, no protege independientemente la política normativa.

### O-07 — Checkpoints A/B sin evidencia contemporánea

No se encontró `START_AUTHORIZED` versionado ni revisión de diseño previa. El gap se registra sin
crear autorización retroactiva.
