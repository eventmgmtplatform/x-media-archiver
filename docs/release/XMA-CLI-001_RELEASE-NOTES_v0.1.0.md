# X Media Archiver v0.1.0 release notes

First bounded local release: catalog public X video metadata, download exact/profile
videos, preserve sidecars/hashes, and durably archive/resume up to ten items with offline status.

Highlights: Firefox read-only session boundary, fail-closed sanitization, SQLite v2 migrations,
atomic downloads, deduplication, checkpoints, rate limiting and Linux standalone bundle.

The distribution includes the complete GPL-2.0-only license, third-party notices, the corresponding
`gallery-dl` 1.32.18 source archive, checksums, a sanitized release manifest, SBOM, requirements,
quick start, and operating documentation.

Known limits: Linux x86_64 only; maximum ten; no scheduler, daemon, mass operation or efficient
remote cursor. Provider availability remains external. Publication still requires the authorized
human release action.
